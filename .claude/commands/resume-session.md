# Resume Session - セッション状態の復元

新規セッション（または `claude -r` で選んだセッション）で前回の続きから再開する入口。**記録と現実（git）を突き合わせ、食い違いを報告してから**再開する。

> クラッシュ復旧: 同じフォルダで `claude -r`（一覧から選ぶ）か新規セッション → `/resume-session`。

## Process

### 1. 記録を読む
- 最新の日付ファイル（`tasks/YYYY-MM/` の最新月の、最大の `DD.md`）の末尾側にある最新の `## HH:MM セッションレポート` が「前回の到達点と次にやること」の本体
- SessionStart が日付を問わず最新のレポートを注入済み（先頭にファイルパスが付く）。注入で足りていれば再読不要。足りなければそのファイルを直接読む。今日のファイルが目印の行だけでレポートが無いときは、レポートのある直近の日まで遡る
- 注入に「レポート未生成セッション」の警告があれば、`/save-session 補完` を先に実行するか選択肢に出す

### 2. 現実と突き合わせる（食い違いは黙って直さず報告）
| 確認 | コマンド | 見るもの |
|---|---|---|
| ブランチ | `git branch --show-current` | レポートの「現在地」のブランチと一致するか |
| 未コミット変更 | `git status --porcelain` | 記録に無い変更は無いか（並走セッションの痕跡かも — 触らず報告） |
| 最新コミット | `git log -1 --oneline` | 「現在地」の SHA と繋がっているか（進んでいれば、その間のコミットも報告） |

### 3. 報告して待つ
平易な日本語で報告し、**ユーザーの指示を待つ**（勝手に作業を始めない）:
1. 現在地（ブランチ・最新SHA）
2. 前回の到達点（レポートの見出し＋「次にやること」）
3. 記録と現実の食い違い（無ければ「一致」）
4. 推奨する次の一手（1行）

レポート未生成の過去セッションが検知されていれば「/save-session 補完 を先に実行するか」も選択肢に出す。
