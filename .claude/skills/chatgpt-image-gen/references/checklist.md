# 画像の点検チェックリスト

上から順に見る。**「致命」が1つでも×なら不合格**。

## A. 依頼どおりか（致命）
- [ ] **主題**: 頼んだものが描かれている（猫を頼んで犬、はダメ）
- [ ] **数**: 登場する物・人の数が指定どおり
- [ ] **画風**: 指定の画風になっている（水彩を頼んで写真風、はダメ）
- [ ] **質感**: 画像を拡大して、画風らしい質感か見る（水彩なら紙のにじみ。粒状のデジタルっぽいざらつきなら「軽微」扱いで報告、利用者が本番用と言っていれば不合格）
- [ ] **縦横比**: 指定どおり（横長を頼んで正方形、はダメ）
- [ ] **入れないもの**: 禁止したものが入っていない

## B. 文字（指定があるときは致命）
- [ ] 一字一句正しい（「OPEN」が「OPFN」「0PEN」になっていないか）
- [ ] 日本語が化けていない・存在しない漢字になっていない
- [ ] 頼んでいない意味不明な文字が目立つ位置にない

生成画像は文字が崩れやすい。**文字は拡大して1文字ずつ読む**こと。

## C. 形の破綻（位置しだい）
主題の目立つ位置なら不合格、隅なら合格＋報告。
- [ ] 手・指の本数、関節の向き
- [ ] 顔（目の数・左右の対称、歯の並び）
- [ ] 体のつながり（腕が3本、足が溶けている）
- [ ] 物の形（自転車の車輪、椅子の脚、建物の直線がぐにゃっとしていないか）
- [ ] 同じ物が不自然に繰り返されていないか

## D. 仕上がり（軽微）
- [ ] ぼやけ・にじみが主題にかかっていない
- [ ] 画像の端が不自然に切れていない（主題の頭や足が切れていないか）
- [ ] 色が指定の雰囲気と合っている

## 修正指示の書き方の例
| 見つけた問題 | 修正指示 |
|---|---|
| 看板が「OPFN」 | 看板の文字を正確に「OPEN」の4文字にしてください |
| 指が6本 | 左手の指を自然な5本にしてください |
| 正方形で出た | 縦横比を16:9の横長にしてください |
| 水彩が粒っぽくデジタル的 | 本物の水彩紙に描いたように、絵の具が紙ににじむ質感にしてください。粒状のざらつきは無くしてください |
| 写真風になった | 写真風ではなく、紙ににじんだ水彩画の画風にしてください |
| 背景に人がいる | 背景の人物をすべて消してください |

直す点は **1回につき3つまで**。多すぎると別の箇所が崩れやすい。
